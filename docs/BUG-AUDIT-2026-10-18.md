# Reliability audit — 18 October 2026

Baseline: `b70d378` on main. Scope: analyzer correctness, report trust, local file handling and browser interactions.

| Problem | Resulting change | Evidence |
| --- | --- | --- |
| `echo secrets.NOT_A_REFERENCE` appeared as a secret reference | Inspect expression bodies, excluding literal text and quoted values | New analyzer regression failed before the fix and passes after it |
| A trusted expression followed by plain context-like text and another expression generated a high script-injection hint | Inspect each expression separately; preserve actual context references, including literal bracket properties | Triggering and non-triggering fixtures pass |
| Lowercase/uppercase references to the same secret appeared as separate entries | Canonicalize named secret references to uppercase before deduplication | Named and dynamic reference regression passes |
| `runs-on: {group: review-runners, labels: self-hosted}` missed the PR runner hint | Inspect explicit object-form labels; group membership remains unresolved | Scalar and list label fixtures pass |
| `needs: [build, 42]` silently dropped the invalid value | Reject malformed dependency shapes before mapping or diagram export | Analyzer and CLI Mermaid failure-path tests pass; browser disables exports |
| An earlier slow file read could replace later edits, Clear, or a newer file | Discard reads whose source revision is stale | Three browser race scenarios pass |
| File rejection was invisible when the editor was empty; Clear showed a syntax error | Keep file feedback outside the analysis result; show Ready for empty input | Empty-editor browser regression passes |
| Job-card and tab redraws lost keyboard focus | Restore focus to the equivalent rendered control | Focus assertions failed before the fix and pass afterward |
| Cards labeled jobs "Clean" without a complete audit and described OIDC-only requests as write access | Show No high hints and distinguish requested OIDC from repository-token write scopes | Browser verifies card labels and selected-job permission details |

GitHub documents [expression literals and quoting](https://docs.github.com/en/actions/reference/workflows-and-actions/expressions), [case-insensitive secret names](https://docs.github.com/en/actions/reference/security/secrets), and [runner/dependency configuration](https://docs.github.com/en/actions/reference/workflows-and-actions/workflow-syntax). The expression helper is lexical and bounded; it does not evaluate expressions or fully validate their syntax.
